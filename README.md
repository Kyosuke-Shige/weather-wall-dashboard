# 空模様

壁掛けタブレット向けの天気ダッシュボードです。GitHub Pages で公開しています。[空模様を開く](https://kyosuke-shige.github.io/weather-wall-dashboard/)

## Android で使う

1. タブレットを横向きにして、Chrome で上のリンクを開きます。黒画面が表示されたら「一時表示（10分）」を押すと設定できます。
2. Chrome の確認が出たら、位置情報を許可します。現在地が出ない場合は、右上の地域ボタンを押し、「現在地を取得」で再試行できます。測位が難しい場合は、同じ画面で地域名を検索し、候補を選択します。次回もその地域を表示し、「現在地を取得」で自動測位に戻ります。
3. Chrome のメニューから「ホーム画面に追加」を選び、「インストール」が表示されれば選択します。ホーム画面の「空模様」から起動すると、対応する環境ではブラウザのアドレスバーが消えて横向きで開きます。通常のタブでは左下の「全画面」も使えます。

## 表示と更新

- 端末時刻の **07:00〜09:00** にダッシュボードを表示し、**09:00〜翌07:00** は黒画面を表示します。右上の「自動消灯 ON/OFF」でスケジュールを切り替えられます。「一時表示（10分）」は設定を保存せず、時間が過ぎるとスケジュールに戻ります。
- 黒画面中のバックライトや本体の電源状態は Android 側の設定に従います。ページは天気の表示中に対応ブラウザへ画面のスリープ防止を要求し、黒画面に移ると解除します。指定時刻にロックやスリープから復帰する機能は Android 側で設定します。
- 表示中は15分ごとに更新します。タブに戻った際や通信が復旧した際にも再取得します。通信に失敗した場合は、同じ地域でそのページを開いてから取得した前回のデータを最終更新時刻とともに表示します。地域を変更した直後や初回取得に失敗した場合は空欄です。
- 上部の時計と最終更新時刻は端末時刻です。時間別・週間予報は指定した地域の現地時刻で表示します。

## データと公開

予報取得時は緯度・経度を Open-Meteo に送信します。地域の手動検索時は入力した名前を Open-Meteo の地域検索に送信します。地域を手動指定した場合は、選んだ地域名と座標をそのブラウザ内に保存します。[Open-Meteo の天気予報 API](https://open-meteo.com/en/docs) · [地域検索 API](https://open-meteo.com/en/docs/geocoding-api) · [地域データ提供 GeoNames](https://www.geonames.org/)

公開元は `main` ブランチのルートです。静的な HTML と JavaScript で動作します。
